Daily Journal: write a few lines each day, log your mood, check off habits. Works offline.

Free setup (5 minutes):
1. Make a GitHub account and a new repository.
2. Upload every file from this folder.
3. Repo Settings > Pages > deploy from the main branch.
4. Open the link on your phone, then Add to Home Screen.
(Alternative: drag this folder onto netlify.com/drop.)

Privacy: the app's code is public on the free plan, but nothing you write ever leaves your device.
Safety: clearing browser data erases entries. Save a backup from Settings now and then.
